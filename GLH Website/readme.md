# GLH Website

The digital solution made for GLH is running on flask and jinja. All features work correctly except billing and address as they are not needed in the prototype design

How to run the website?
1. Ensure the app.py file is opened within the website folder and is not outside the website folder
2. Click on the app.py to run the file or click the play button on an IDE.
3. After clicking on the file or the play button wait a few seconds. After waiting a link should appear inside the terminal which will allow you to visit the website.
